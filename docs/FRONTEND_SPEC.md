# 浮屿 Atlas · 玻璃地图前端规范

版本：1.1 · 基线日期：2026-09-23 · 适用范围：全屏地图、空间信息工作台、以内容画布为主体的工具界面。

这份规范从当前可运行 Demo 提取，作为后续设计与开发的参考。视觉方向借鉴 Liquid Glass，但参数属于 Atlas 自身的实现，并非 Apple 官方规范或原生渲染器。

## 1. 使用方式

- **做同风格页面**：先看第 2–5 节，再按第 7 节选择组件。
- **接入已有项目**：复制 [设计变量 CSS](reference/atlas-tokens.css)，按第 11 节实现材质和布局。
- **交给设计师或 AI 开发**：使用第 14 节的任务说明，并附上本文件。
- **验收交付**：使用第 13 节的检查表。

文中“基线”指当前 Demo 的实际实现；“要求”指延续该风格必须保持的约定；“建议”是后续项目的改进方向，不表示 Demo 已全部实现。

实现来源：基础布局 [style.css](../src/style.css)、材质与组件 [liquid-glass.css](../src/liquid-glass.css)、交互 [main.js](../src/main.js)、玻璃行为 [glass.js](../src/glass.js)、底图配置 [basemaps.js](../src/basemaps.js)。当前加载顺序是基础样式在前、Liquid Glass 样式在后，实际值仍取决于选择器优先级。

## 2. 设计原则

1. **地图始终是主体。** 铺满视口，浮层之间的空隙可以操作地图。
2. **导航轻、内容稳。** 搜索、导航、工具栏采用较清透的胶囊玻璃；信息面板使用稍厚的雾面衬底。
3. **文字独立于透明度。** 只调背景颜色的 alpha，文字和图标保持自身清晰度。
4. **用光表达厚度。** 单像素亮边、内侧高光、柔和投影共同形成层次，不依赖粗描边。
5. **颜色承担含义。** 绿色强调可操作和选中状态，地点类别辅以图标、名称；不只靠颜色区分。
6. **控件随空间变化。** 右侧面板收起时，地图工具栏靠右；展开时恢复到面板左侧。
7. **动效服务反馈。** 轻微按压和短距离移位即可；地图上不叠加持续扫光、漂浮或脉冲动画。

避免：全屏玻璃遮罩、整块面板设置 `opacity`、所有小按钮各自模糊、重度霓虹发光、为“深色模式”给底图反色、关闭侧栏后留下工具栏空位。

### 3.2 手机布局：≤760

- 外边距 12；顶部第一行是品牌和导航，第二行是搜索。
- 品牌、导航胶囊高 51；搜索内容区高 48，外框含边框略高。
- 左右面板默认收起；左下角“发现地点”展开左栏，Dock 图层按钮展开右栏。
- 左栏宽 `min(294px, 100% - 80px)`；右栏宽 254；面板距顶 139。
- 面板最大高度 `100dvh - 246px`，内容在面板内滚动。

- 地图工具栏宽 48、距右 12、距底 109；打开右侧设置时暂时隐藏，避免遮挡。
- Dock 靠右、距底 36，以图标为主；“发现地点”按钮靠左、距底 36。
- 地图署名保持可访问。生产移动端建议补充 `env(safe-area-inset-*)`；当前 Demo 尚未专门适配刘海屏安全区。

### 3.3 浮层与事件

| 容器 | 当前 z-index | 约定 |
| --- | ---: | --- |
| 地图根节点 | 0 | 内部瓦片、标记、Popup 交由 Leaflet pane 管理 |
| 地图装饰文案 | 500 | 不承担核心交互 |
| 两侧面板、地图工具、状态 | 800 | 不挡住无关地图区域 |
| 底部 Dock | 850 | 始终可返回探索模式 |
| 手机左栏 | 900 | 展开时位于地图工具上方 |
| 顶部容器 | 1000 | 外层 `pointer-events: none`，实际胶囊恢复 `auto` |
| 搜索结果、Toast | 2000 | 搜索结果仍受顶部祖先的层叠上下文约束 |

不要仅通过无限增大 z-index 修复遮挡：`transform`、`opacity`、`backdrop-filter` 都可能影响层叠或背景采样。新增容器后需实测玻璃和 Popup。

## 5. 玻璃材质

### 5.1 材质分工

| 材质 | 使用位置 | 基础颜色 alpha | 表现 |
| --- | --- | --- | --- |
| 信息玻璃 `.glass` | 概览、列表、设置、地点详情 | `clamp(0, A + .08, 1)` | 稳定衬底、轻微渐变、柔和投影 |
| 控件玻璃 `.glass.liquid-control` | 顶部胶囊、地图工具、Dock | `A × .72` | 更清透，局部映光，胶囊轮廓 |
| 高可读浮层 | 搜索结果 / Toast | .92 / .86 | 优先读取与即时反馈 |
| 用户增强可读性 | 主要玻璃面板 | .91 | 加深衬底、弱化高光 |
| 系统减少透明度 / 高对比 | 主要玻璃面板 | .96 | 关闭背景模糊和高光描边 |

`A = --glass-alpha = 1 - 透明度百分比 / 100`。滑块数值是基础透明度，**不是最终像素的透明度**：信息玻璃和控件玻璃有不同权重，渐变还会进一步影响合成结果。

### 5.2 预设与范围

| 预设 | 透明度 | A | 模糊 | 信息玻璃 alpha | 控件玻璃 alpha |
| --- | ---: | ---: | ---: | ---: | ---: |
| 清透 | 72% | .28 | 12px | .36 | .2016 |
| 柔雾（默认） | 58% | .42 | 22px | .50 | .3024 |
| 凝霜 | 28% | .72 | 28px | .80 | .5184 |

透明度滑块范围 15–80；模糊范围 0–32px；饱和度倍率固定 1.55。手动改变滑块后清除预设选中态，摘要同步显示，例如 `59% · 22px`。

### 5.3 光与厚度

- 内容面板：145° 表面渐变，亮部过渡至 42% 处透明；外阴影为 `0 12px 32px / .10` 加 `0 2px 7px / .05`。
- 控件：指针位置附近的径向映光，加 165° 弱线性高光；外阴影 `0 8px 24px / .13`。
- 边缘：用 1px 渐变遮罩形成轮廓；伪元素必须 `pointer-events: none`。
- 内侧：顶部 1–1.5px 高光，底部极轻的 1px 反光。
- 保持真实背景采样，拖动地图时，面板下的颜色会自然变化。

这是 `backdrop-filter`、透明色和渐变的 CSS 实现。没有真实几何折射、光线追踪或放大透镜采样，不应把它描述成原生 Liquid Glass 渲染器。

## 6. 字体与图标

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display',
  'PingFang SC', 'Noto Sans SC', sans-serif;
```

优先系统字体；系统没有指定字体时使用回退字体，不要求自行分发 Apple 字体文件。

| 角色 | 桌面基线 | 字重 / 说明 |
| --- | --- | --- |
| 页面问候标题 | 28px | 600，字距 -1.1px |
| 地点详情标题 | 29px，手机 27px | 600 |
| 面板标题 | 14px | 600 |
| 地点列表标题 | 13px | 500 |
| 正文、搜索、主要操作 | 11–12px | 正文行高 1.6–1.8 |
| 辅助说明、类别 | 9–11px | 保持足够对比 |
| 装饰英文、品牌副标 | 6–10px | 不承载唯一的必要信息 |

**后续生产页面建议**：阅读型正文采用 14–16px，辅助文字尽量 ≥12px；允许扩大卡片或减少同时展示的内容。当前 9–12px 的密集布局是 Demo 的紧凑取舍，不代表适合所有人群和设备。

图标使用 Lucide 线性风格，默认线宽 1.65，工具图标约 19px。按名称导入需要的图标，避免导入整套集合。纯图标操作需可访问名称；类别信息同时提供名称和图形。

| 地点列表项 | 最小高 66，圆角 18，图形 39×39 | 默认、悬停、选中、键盘焦点 |
| 主按钮 | 高 ≥44，胶囊 | 绿色填充与内高光；悬停加深、按下轻缩 |
| 图标按钮 | 常规 44×44，圆形 | 明确名称；操作后状态可理解 |
| 地图工具栏 | 宽 52，内部按钮 42×38 | 纵向分组；与右栏可见性联动 |
| 底部 Dock | 内边距 7、间距 5，按钮 ≥45×45 | 当前工具有选中态；手机压缩至 ≥40×40 |

| 图层开关 | 轨道 36×22，滑块 18×18 | 整行标签可点击；开关状态与地图一致 |

当前部分地图工具和分段控件命中区域小于 44px。新项目建议尽量达到至少 44×44 CSS px 的可点击区域，可用标签或外层命中区扩展，不必把可见图形做大。此值是本项目的体验建议，不是对当前 Demo 的合规认证。

## 8. 交互状态与工具栏联动

### 8.1 桌面状态表

| 状态 | 左栏 | 右栏 | 地图工具栏 |
| --- | --- | --- | --- |
| 默认 | 显示 | 显示 | 位于右栏左侧 |
| 隐藏设置 | 显示 | 隐藏 | 距右边缘 24；≥1600 时 32 |
| 专注模式 | 隐藏 | 隐藏 | 同上，自动靠右 |
| 退出专注，设置未隐藏 | 恢复 | 恢复 | 恢复至对应断点的面板左侧位置 |
| 退出专注，设置仍隐藏 | 恢复 | 隐藏 | 保持靠右 |

位置过渡：300ms，`cubic-bezier(.2,.8,.2,1)`。仅移动工具栏，不改变地图中心、缩放、地点或用户的图层选择。

当前 CSS 使用 `.focus-mode`、`.hide-settings`、`.mobile-open`。其中 `.hide-settings` 在手机断点实际表示“展开设置”，这是历史实现，**不建议在新项目复制这种相反语义**。

新项目建议用清晰状态：

```ts
type ViewState = {
  focusMode: boolean;
  desktopSettingsVisible: boolean;
  mobilePanel: 'none' | 'places' | 'settings';
  activeTool: 'explore' | 'measure';
};
```

按钮的 `aria-expanded` 应反映面板最终是否可见，而非直接照抄某个类名的真假值；状态变化与断点变化都需同步。

### 8.2 搜索、选择、测距

- `⌘K / Ctrl+K` 聚焦搜索；回车选取当前实现中的首个匹配地点。
- 搜索为空时收起结果；无匹配时给出具体示例，不展示空白框。
- 点击地点或列表项更新详情，并将选中地点放到不会被 Popup 覆盖的位置。
- 收藏按钮切换状态；收藏持久化到当前浏览器，失败时提示本次会话仍可使用。
- 切换到测距后关闭地点详情，在地图空白处依次选择两点；显示直线距离。
- `Esc` 收起搜索、退出测距并关闭手机左栏；当前并不负责关闭全部类型面板。

移植时若实现完整搜索建议列表，需补齐上下键、当前项与焦点管理；当前 Demo 没有完整 combobox 键盘模型。

### 8.3 反馈与错误

- 地图加载状态直接放在底图选择器下方。
- 超过 12 秒未完成时提示加载较慢，并提供重试；加载失败区分全部失败与部分瓦片失败。
- 不能因底图失败清空用户收藏或重置玻璃设置。
- 路线示意明确标注“示意”，不将折线展示为实际道路导航。
- 导出包含中心、缩放、底图、收藏、玻璃参数与增强可读性状态。

## 9. 动效与性能

| 动效 | 基线 |
| --- | --- |
| 按钮背景、阴影 | 220ms |
| 按钮按下 | 缩放 .96；280ms，`cubic-bezier(.2,.85,.25,1.2)` |
| 滑块按下 | 滑块放大 1.13；250ms |
| 缩略图悬停 | 上移 2px；250ms，仅支持 hover 的设备 |
| 精细调整箭头 | 旋转 180°；200ms |
| 工具栏靠右 / 复位 | 300ms |
| 局部映光 | 鼠标事件触发，`requestAnimationFrame` 合并同帧更新 |

要求：

- 仅小面积导航和工具容器使用指针映光；触屏、减少动态效果或增强可读性时不更新。
- 不对整张地图持续做位移滤镜、模糊动画或颜色动画。
- 不给每个文本节点和列表项添加 `backdrop-filter`，复用外层材质。
- 不批量添加 `will-change`；先定位实际性能瓶颈。
- 减少动态效果偏好下取消装饰过渡和按压缩放。当前全局减少动效规则也依赖基础 `style.css`，单独复制材质 CSS 时需补齐。

## 10. 可读性、兼容与限制

要求：

- 在灰色、深色、暖色背景分别检查文字；接入真实服务后，再检查高密度道路区域，不只看单一截图。
- 保留用户可见的“增强可读性”，并响应系统减少透明度、增强对比度设置。
- 不支持 `backdrop-filter` 时改用 .96 alpha 衬底；不支持 mask 合成时取消装饰描边。
- 表单控件有 label；图标按钮有名称；选中态、展开态与屏幕内容同步；焦点可见。
- 减少透明度优先于用户的清透预设；以能看清内容为准。
- 地图署名和必要状态不要被浮层遮挡。

当前只做过构建、交互和部分桌面/手机尺寸检查，**没有完成全浏览器、屏幕阅读器或对比度合规审计**。透明背景的对比度会随地图和参数变化，不能仅凭两个色值宣布通过。

已知层叠差异：浅色主题同时启用 `.readability` 和系统减少透明度时，现有选择器可能让衬底保持 .91，而关闭模糊的规则仍生效。新项目应把系统回退统一到 .96，并覆盖增强可读性选择器；下方移植示例已处理这一优先级。

后续建议：确认目标浏览器版本；测试 Safari、Chromium、Firefox；检查放大字体、键盘导航、屏幕阅读器、超窄屏及短视口。关键状态文案不得只依靠淡色小字。

## 11. 最小移植示例

先把 [atlas-tokens.css](reference/atlas-tokens.css) 复制到新项目并导入。下面是最小材质示例；完整映光描边和现有地图适配见 `src/liquid-glass.css`。

```css
@import './atlas-tokens.css';

.atlas-glass {
  position: relative;
  --surface-alpha: clamp(0, calc(var(--glass-alpha) + .08), 1);
  color: var(--ink);
  border: 1px solid var(--surface-edge);
  border-radius: var(--atlas-radius-panel);
  background:
    linear-gradient(145deg, var(--surface-shine), transparent 42%),
    rgb(var(--material-rgb) / var(--surface-alpha));
  backdrop-filter: blur(var(--glass-blur)) saturate(1.55);
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(1.55);
  box-shadow: var(--atlas-shadow-panel);
}

.atlas-glass--control {
  --surface-alpha: calc(var(--glass-alpha) * .72);
  border-radius: var(--atlas-radius-pill);
  box-shadow: var(--atlas-shadow-control);
}

[data-readability='enhanced'] .atlas-glass {
  background: rgb(var(--material-rgb) / .91);
}

@media (prefers-reduced-transparency: reduce), (prefers-contrast: more) {
  .atlas-glass, [data-readability='enhanced'] .atlas-glass {
    background: rgb(var(--material-rgb) / .96);
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
  }
}

@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .atlas-glass, [data-readability='enhanced'] .atlas-glass {
    background: rgb(var(--material-rgb) / .96);
  }
}

@media (prefers-reduced-motion: reduce) {
  .atlas-glass, .atlas-glass * { animation: none !important; transition: none !important; }
}
```

`atlas-tokens.css` 支持 `.dark-map` 或 `[data-atlas-theme="dark"]` 覆盖主题。控件类与信息类放在同一个元素上，例如 `class="atlas-glass atlas-glass--control"`，避免无意义的玻璃嵌套。

侧栏联动可用明确状态表达，下面是新项目建议写法，不是对现有 DOM 类名的逐字复刻：

```css
.workspace {
  --edge: 24px;
  --controls-expanded-right: 300px;
}
.map-view-tools {
  position: absolute;
  right: var(--controls-expanded-right);
  transition: right 300ms cubic-bezier(.2,.8,.2,1);
}
.workspace[data-settings-visible='false'] .map-view-tools {
  right: var(--edge);
}
@media (min-width:1600px) {
  .workspace { --edge:32px; --controls-expanded-right:328px; }
}
@media (min-width:951px) and (max-width:1150px) {
  .workspace { --controls-expanded-right:274px; }
}
@media (min-width:761px) and (max-width:950px) {
  .workspace { --controls-expanded-right:250px; }
}
@media (max-width:760px) {
  .workspace { --edge:12px; --controls-expanded-right:12px; }
  .workspace[data-settings-visible='true'] .map-view-tools { display:none; }
}
@media (prefers-reduced-motion:reduce) {
  .map-view-tools { transition:none; }
}
```

不要在新项目里不断追加覆盖规则来复制 Demo 历史。建议按“变量 → 布局 → 材质 → 组件 → 状态 → 响应式/无障碍”组织，并为框架组件保留一致的语义。

## 12. 地图接入约定

公开版本保留 `standard`、`english`、`mobile`、`gray`、`blue`、`warm` 六种外观入口，默认选择灰色。没有预置瓦片提供者、域名、服务名、远程缩略图或地图署名链接。未配置时显示抽象背景与「未配置底图 · 当前为界面演示」。

接入流程：复制 `src/basemaps.example.json` 为被 Git 忽略的 `src/basemaps.local.json`，填写自己的瓦片模板和必要署名。`src/basemaps.js` 读取可选配置；没有配置也能启动。

| 字段 | 用途 / 默认值 |
| --- | --- |
| `defaultBasemap` | 默认入口，默认为 `gray` |
| `attribution` | 提供者要求的署名，公开模板为空 |
| `styles[].id` | 六个固定外观入口之一 |
| `styles[].name` | 界面名称 |
| `styles[].url` | 瓦片模板，公开模板为空 |
| `styles[].preview` | 可选预览图，公开模板为空 |
| `styles[].tileSize` | 瓦片尺寸，默认 256 |
| `styles[].zoomOffset` | 请求层级偏移，默认 0 |
| `styles[].maxNativeZoom` | 原生层级上限，默认 19，需按服务调整 |
| `styles[].dark` | 是否搭配深色玻璃 |

地图显示缩放为 3–19。接入前核对投影、原点、瓦片大小、坐标基准、层级和模板中的行列顺序；地址本身不决定这些参数。切换时保留中心和显示缩放，已配置服务保留其原始配色和必要署名。

本地配置虽不会提交，但构建后会进入浏览器资源；发布产物前需重新检查，服务端凭据不要放入前端配置。

业务能力边界：当前是 7 个静态地点、750 米探索圈、两点直线测距和示意路线。未配置时的抽象背景不是地理底图。路线规划、实时天气、客流、营业状态及设备定位均不应被推断为已实现。

## 13. 交付验收清单

### 视觉与布局

- [ ] 地图全屏，浮层之外仍可拖动和缩放。
- [ ] 导航与内容的玻璃厚度有区分；文字未被整体透明度影响。
- [ ] 浅色、深色、高密度背景下的主次信息可辨认。
- [ ] 390×844、1044×822、1440×900、≥1600 宽及短视口分别检查，无页面横向溢出。
- [ ] 面板过长时可滚动，默认状态不出现不可达的控件。

### 状态与交互

- [ ] 专注模式、单独隐藏右栏、恢复面板时，地图工具位置符合第 8 节。
- [ ] 连续切换与改变窗口尺寸后，选中态和 `aria-expanded` 仍正确。
- [ ] 三种预设、手动滑块、实时摘要、增强可读性均可操作。
- [ ] 无配置时能运行且不请求远程底图；有配置时逐项核对瓦片尺寸、层级、署名、失败重试及切换效果。
- [ ] 搜索、收藏、测距、退出工具模式、导出没有因样式修改回归。

### 键盘、系统偏好与性能

- [ ] Tab 焦点清楚；图标按钮有名称；滑块支持方向键。
- [ ] 减少动态效果、减少透明度、高对比偏好得到尊重。
- [ ] 缺少模糊或 mask 支持时有可读回退。
- [ ] 拖动地图时无持续全屏特效；映光只在小范围操作时更新。
- [ ] 生产构建通过；浏览器没有新增运行错误；记录实际验证过的环境，不扩大“已通过”的范围。
